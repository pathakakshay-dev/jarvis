Voice

The microphone turns on only while Hold to talk is pressed, and for a moment when you press List microphones so the names can be shown. There is no background listening. The clip stays in this page until you press Transcribe clip. Speech is transcribed on this computer with Whisper small. Compare decoding keeps one clip on this computer only after you agree, runs four local decoders, then deletes the clip. Play and new replies use Microsoft Edge TTS, which sends that reply text to Microsoft. If Edge TTS is unavailable, this browser speaks with Windows voices and the text stays here. Mute blocks automatic speech. Resume does not replay speech.
